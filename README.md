# 🎵 Chinook Music Store Analytics Dashboard - Power BI

## 📌 Project Overview

This project presents an interactive Business Intelligence dashboard built using the Chinook Database. The dashboard provides comprehensive insights into sales performance, customer behavior, music trends, and business growth through advanced data visualization and analytics.

The solution combines SQL querying, Power Query transformations, DAX calculations, and professional dashboard design to support data-driven decision-making.

---

## 🎯 Project Objectives

* Analyze overall business performance and revenue trends.
* Identify top-performing artists, albums, and music genres.
* Evaluate customer purchasing behavior and spending patterns.
* Monitor sales growth and revenue distribution.
* Apply advanced SQL techniques including Joins, Subqueries, CTEs, and Window Functions.
* Create an interactive dashboard experience with dynamic filtering and navigation.
